# Tech Soluciones

Sitio web corporativo para Tech Soluciones, empresa de servicios tecnológicos con más de 50 años de experiencia.

## Contenido

- Presentación de la empresa
- Formulario de solicitud de asesoría
- Tabla de planes (Básico, Medio, Avanzado)

## Tecnologías

- HTML5
- CSS3
- Google Fonts (Inter)

## Ver online

Abrir `index.html` en cualquier navegador.
